# Vasi - A Voice assisted smart interface

This is currently a PWA (Progressive Web Application) designed to be one's personal assistant. Uses, voice commands to interact with the user and provide information. The application uses the Azure OpenAI GPT-4o Realtime API to generate responses to user queries. The application also uses the Azure AI Search service to search for information in a knowledge base. And also has an integration with Azure Cosmos DB to store voice notes.

Currently supports the following features,

1. Personal knowledge base search via Azure AI Search
2. Records voice notes into Azure Cosmos as Text
