# Vasi - A Voice assisted smart interface

A [PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/What_is_a_progressive_web_app) that acts as a personal assistant using voice commands. It leverages Azure OpenAI GPT-4o Realtime API for responses, Azure AI Search for knowledge base queries, and Azure Cosmos DB for storing voice notes.

Features:

1. Knowledge base search via Azure AI Search
2. Voice notes stored as text in Azure Cosmos DB
